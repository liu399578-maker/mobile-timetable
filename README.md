# 手机课表

这是一个不含姓名和学号的手机课表网页，适合用 GitHub Pages 免费托管。它会：

- 默认显示当前学期周次（校历共 19 个教学周）；
- 按周过滤双周课和第 13—16 周课程；
- 提供“今天 / 本周 / 全部”三种查看方式；
- 采用蓝灰莫兰迪配色，本周课程可在一屏内看完；
- 点击紧凑课程块即可查看完整课程名、教师和时间；
- 显示每门课准确的开始和结束时间；
- 可把全部课程导入手机日历，并提前 15 分钟提醒；
- 添加到手机主屏幕后支持离线查看。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个公开仓库，例如 `my-timetable`。
2. 把本文件夹内的全部文件上传到仓库根目录。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，保存。
5. 等一两分钟，GitHub 会给出网址。用手机打开后，点页面右上角“放到桌面”。

> 隐私提示：GitHub Pages 通常是公开的。本页面已经去掉姓名、学号和班级，但仍包含课程、教室和教师信息。若不想公开，请不要启用 GitHub Pages，可直接把 `index.html` 发到手机临时查看（离线安装功能需通过网站访问）。
